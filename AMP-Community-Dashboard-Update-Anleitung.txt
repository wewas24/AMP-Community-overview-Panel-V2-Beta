AMP Community Dashboard v2.4.4 – Update-Anleitung

Diese Anleitung verwendet ausschließlich Beispielwerte und bewahrt alle vorhandenen Daten.

1. Dienst stoppen und Sicherung erstellen

   sudo systemctl stop amp-community-dashboard
   sudo cp -a /opt/amp-community-dashboard /opt/amp-community-dashboard-before-v2.4.4

2. Update sicher einspielen

Das Paket nicht direkt über den Projektordner entpacken. In einen temporären Ordner entpacken und danach alle Dateien außer data/ übernehmen:

   sudo mkdir -p /opt/amp-dashboard-update
   sudo unzip -o /opt/amp-community-dashboard-v2.4.4-security-e2e.zip -d /opt/amp-dashboard-update
   sudo rsync -a --exclude=data/ /opt/amp-dashboard-update/ /opt/amp-community-dashboard/
   sudo chown -R amp:amp /opt/amp-community-dashboard

Der Ordner data/ bleibt vollständig erhalten: Datenbank, Administratorkonten, Einstellungen, Sicherungen, Uploads und Geheimnisse werden nicht überschrieben.

3. Dienst und Nginx übernehmen

   sudo cp /opt/amp-community-dashboard/amp-community-dashboard.service /etc/systemd/system/amp-community-dashboard.service

- nginx-security-http.conf weiterhin im globalen Nginx-http{}-Bereich einbinden.
- Den aktuellen nginx-snippet.conf-Inhalt in den HTTPS-Serverblock kopieren.
- Die Zeilen proxy_buffering off; und proxy_cache off; sind für Live-Updates erforderlich.
- Eine alte Zeile proxy_cookie_path / /uebersicht/; entfernen, falls vorhanden.

Danach:

   sudo nginx -t && sudo systemctl reload nginx
   sudo systemctl daemon-reload
   sudo systemctl restart amp-community-dashboard
   sudo systemctl status amp-community-dashboard --no-pager
   curl -fsS http://127.0.0.1:3100/health

4. Nach dem Update prüfen

- Dashboard im Browser mit Strg+F5 neu laden.
- Anmelden und prüfen, ob Gruppen, Connect-Buttons und Banner korrekt dargestellt werden.
- Unter Überwachung eine Testbenachrichtigung senden.
- Prüfen, dass oben die Live-Verbindung keinen Wiederherstellungshinweis zeigt.
- In „Einstellungen → Allgemein → Erweiterte Einstellungen“ optional vertrauenswürdige Community-Domains eintragen. Das sind nur Domainnamen, je Zeile, ohne https:// und ohne Pfad.
- Beim Hinzufügen eines Servers „Server erkennen“ wählen. V2.4.4 übernimmt Spieladresse, Port und – wenn eindeutig – die passende Abfrageart aus der Community-Seite. Bei Arma 3 wird der Query-Port für die Steam-Statusabfrage getrennt gesetzt.

V1-Migration

Bei einer reinen V1-Installation vor dem ersten Start erst ausführen:

   cd /opt/amp-community-dashboard
   sudo -u amp node migrate-v1.mjs

Nur wenn die Ausgabe korrekt ist:

   sudo -u amp node migrate-v1.mjs --apply

Das Werkzeug sichert zuerst, prüft ohne Änderungen, migriert, validiert die Anzahl der Server und behält die V1-Originaldateien unverändert.
